## The line

> I ran a million simulations of this moment — every single one ended with me saying hi.

A million simulated futures collapse into the smallest possible gesture. The
twist, the machine voice, and the pickup itself are one sentence — 86
characters, one breath, zero pressure.

## How it was chosen

Three original variants were written fresh for this bounty and judged blind,
pairwise, against the published judge brief (genuine pickup line, twist,
machine voice, one breath, no pressure). The winner beat both rivals and also
beat our best previous judged one-liner (developer-excuse, 501.265) on the
brief's first criterion — an excuse is not a pickup line at all. See
`variants-self-judge.md` in the work directory for the full scoring.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, 86 characters, well inside the
1–200 gate). Pure Python standard library only; the output is deterministic —
the same bytes on every run.
